# Her Health Advocate

**Status:** original prototype (SheInnovates 2023 hackathon), kept as it was built

**Code:** https://github.com/arushi-08/her-health-advocate
**Team:** Aditi, Arushi, Krit, Sharika

## What it is

A web app that helps women advocate for their own health. This is where Herada
started.

- **Maya**, an AI chat assistant for questions about health, lifestyle, hygiene
  and safety
- **Daily diary** for mood, sleep and notes, with emotion tracking from the text
- **Find Others**, a page for connecting with other women nearby
- Accounts, and local weather as a wellbeing input

## Why it lives in its own repository

It is a team project in a teammate's GitHub account, released into the public
domain, so this folder links to it instead of copying it.

It also can't be hosted on this site. GitHub Pages serves static files only, and
this app needs a Python server (Flask), a MongoDB database and a paid OpenAI key.
To show it working, record a short screen capture and put the video or a few
screenshots in a `public/` folder here.
