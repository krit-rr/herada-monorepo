# Women's Health Bible

A free educational guide that gives women the foundational medical and insurance
knowledge to navigate the healthcare system.

## Where it lives

The working draft is a Google Doc for now.

- Google Doc: _add link_

The public page is `site/bible/index.html`, which currently describes the guide
and collects interest by email.

## Structure

1. Introduction
2. Essentials (insurance terminology, hormonal basics)
3. Advocacy
4. Life Stages (in progress)

## Moving it into the repo later

When the draft is stable, export each section from the Google Doc as Markdown
into this folder (`01-introduction.md`, `02-essentials.md`, ...) and publish the
text on the site. Until then, don't keep two copies: the Google Doc is the only
source.
